# QFRL Highway Energy Efficiency Optimization

This project aims to reproduce the results from the paper:
"Quantum federated reinforcement learning-based energy efficiency optimization for IRS-assisted underlaying UAV communication"
by Haneef Khan, Neeraj Joshi, Abdoh Jabbari, Hussein Zangoti, Hussien T. Alrakah, Ishan Budhiraja.

Initially, this repository will reproduce the paper's original scenario exactly as described. Later, the model will be adapted and extended to a highway scenario.
